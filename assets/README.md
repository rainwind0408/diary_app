## 这是什么

折花日记是一款 Android 个人日记应用，水彩手帐风格，打开就像翻开一本纸质笔记本。

所有日记、图片和录音都**只保存在你的手机里** —— 不用注册账号，不用联网（AI 助手与天气除外），不收集任何数据。

## 功能一览

**✍️ 书写**

- 单页连续书写：不翻页、不限字数，页面随文字自动变长
- 图片附件：拍照或从相册选图，可拖拽摆放、缩放、旋转
- 语音备忘：录音后贴在日记里，随时回放
- 13 种日记模板，加上丰富的贴纸与装饰素材
- 标签分类与心情标记

**🗂 整理与回顾**

- 卡片流浏览、标签云筛选、全文搜索
- 日历视图、写作热力图、字数与心情趋势、年度报告
- 日记星座图：把每篇日记连成一张星图，可拨动指针逐日查看
- 20 种成就徽章，记录写作里程碑

**🎨 主题与氛围**

- 二十四节气主题：背景与配色随节气自动切换
- 写日记时自动记下当时的天气与地点，显示在日记顶部
- 深色模式；字体大小可调

**🔒 安全与数据**

- 日记可以单独上锁：4 位数字密码，或者**用手机已录入的指纹**快速解锁
- ZIP 一键备份与恢复，图片、录音一并打包
- 可接收其他应用分享的文字，直接开写

**🤖 AI 助手（可选）**

- 内置 AI 聊天，可帮你查找、整理、分析自己的日记
- 支持国内主流大模型 API，填入自己的接口地址与密钥即可
- 支持语音输入与朗读；朗读也可改用手机自带的语音引擎，离线可用

## 安装方法

### 方法一：直接安装 APK（推荐）

1. 到本仓库的 [Releases](https://github.com/rainwind0408/diary_app/releases) 页面下载最新的 `.apk` 文件
2. 在手机上打开安装包，按提示允许「安装未知来源应用」
3. 安装完成即可使用，无需任何配置

### 方法二：从源码构建

需要 Flutter 3.x（含 Dart 3.x）与 Android SDK：

```bash
git clone https://github.com/rainwind0408/diary_app.git
cd diary_app
flutter pub get
flutter build apk --release
```

构建产物在 `build/app/outputs/flutter-apk/app-release.apk`。
想在真机上调试运行，用 `flutter run` 即可。

## 系统要求

- Android 6.0（API 23）及以上
- 首次启动无需联网；使用 AI 助手或天气功能时需要网络
- 指纹解锁需要手机已在系统设置中录入指纹

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 相机 / 相册 | 添加图片附件 |
| 麦克风 | 语音备忘、AI 语音输入 |
| 位置 | 在日记顶部记录当时的地点与天气 |
| 通知 | 写作提醒 |
| 生物识别 | 指纹解锁日记。只做本机门禁，不读取、不上传任何指纹数据 |

所有数据只保存在手机本地，不会上传到任何服务器。

## 常见问题

**Q：日记内容会上传到云端吗？**
不会。日记正文、图片、录音全部存放在手机本地目录与本地数据库中。

**Q：密码忘了怎么办？**
密码只保存哈希值，无法找回，也无法绕过。请务必记好密码。

**Q：AI 助手是必须的吗？**
不是。不填 API 密钥时，其余所有功能都不受影响。

**Q：换手机怎么迁移？**
设置 → 导入与导出 → 导出备份，会生成一个 ZIP 文件；在新手机上导入即可。
