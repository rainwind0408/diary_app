# assets/audio

齿轮日期检索器的啮合音效。

## 文件

| 文件 | 说明 |
|---|---|
| `gear_tick_1.wav` | 齿轮咬合"咔哒"声，变体 1 |
| `gear_tick_2.wav` | 变体 2（谐振略高、更暗） |
| `gear_tick_3.wav` | 变体 3（谐振略低、更亮） |

三个变体在播放时轮换（`_tick()` 里 `_tickSeq % 3`）——
只用一个采样连播会听出明显的电子重复感。

## 规格

- 44100 Hz / 16bit / **单声道** / **90 ms** / peak ≈ 0.85
- 结构：冲击瞬态（白噪声 × 2.5ms 衰减）+ 金属谐振（3 个非谐分音 × 22ms 衰减）
  + 低频闷响（168Hz × 16ms 衰减）

## 重新生成 / 调参

```bash
python 不推送/工具/生成齿轮音效.py
```

想更"重"就把低频（`thud`）比重调高；想更"脆"就把 `f_ring` 往上抬。
脚本纯标准库（`wave` + `math` + `random`），不依赖 numpy。

也可以直接换成自己的录音素材 —— 只要满足上面的规格（≤100ms、单声道、
44.1kHz、无长尾混响），代码不用改。

## 播放

- 走 `audioplayers` 的 `PlayerMode.lowLatency`（SoundPool 语义：上一条没播完就丢弃），
  音量 0.45；
- **每个档位 = 一个齿**，所以"每啮合一次响一声"在物理上就是对的；
  快速滑动时天然变成密集的"哒哒哒"，不需要额外节流；
- 用户可在齿轮卡右上角关闭（key `gear_sound_enabled`，默认开）；
- 文件缺失时 audioplayers 会静默失败，不影响功能。
